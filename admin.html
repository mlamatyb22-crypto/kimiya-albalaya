ربط الموقع بـ GitHub

خطوة تُعمل مرة واحدة فقط، ليتمكّن هذا القسم من حفظ التعديلات على الموقع.

  1. افتح صفحة إنشاء مفتاح جديد في GitHub.
  2. في Repository access اختر Only select repositories ثم اختر kimiya-albalaya.
  3. في Permissions اجعل Contents على Read and write.
  4. اضغط Generate token وانسخ المفتاح والصقه هنا.

يُحفظ المفتاح مشفّراً بكلمة المرور، فلا يُفتح إلا بها.
