# كيمياء البلايا والمحن

كتيّب إلكتروني: عشر قواعد من القرآن الكريم وأحاديث أهل البيت عليهم السلام في مواجهة البلايا والمحن قبل نزولها وأثناءه.

- `index.html`: الموقع
- `book.pdf`: النسخة المطبوعة (PDF بروابط تفاعلية)
- `cards/`: صورة لكل قاعدة
- `media/` و `data/media.json`: مقاطع القواعد

## رياضياتنا حياة

- `math/index.html`: كتاب رياضيات تفاعلي لثالث ثانوي مسارات (22 درسًا، رسوم متحركة، ملخصات، أسئلة، مقاطع).
