# ريموت الشاشة بالجوال (Dansat DTD6521BU)

جسر صغير يشتغل على الماك (أو أي جهاز ببايثون)، ويعرض صفحة ريموت على الجوال، ويرسل الأوامر للشاشة عبر ADB على الواي فاي.
بدون مكتبات خارجية. يحتاج فقط `python3` و`adb`.

> حالة الاختبار: المنطق مختبَر بـ adb وهمي. ما جُرّب على الشاشة الفعلية بعد، ولا يشتغل إلا بعد تفعيل ADB على الشاشة.

## الخطوات
1. **على الشاشة:** الإعدادات > حول > اضغط Build number سبع مرات > خيارات المطوّر > فعّل **USB debugging** (و**ADB over network** إن وُجد). سجّل عنوان IP للشاشة.
2. **على الماك:** `brew install android-platform-tools`
3. **تحقق:** `adb connect IP_الشاشة:5555` ووافق على الطلب الظاهر على الشاشة (اختر "السماح دائماً").
4. **شغّل الجسر:**
   ```
   cd tv-remote
   python3 server.py --tv IP_الشاشة
   ```
   (اختياري: `--pin 1234` لرقم سري)
5. **من الجوال** (نفس الواي فاي): افتح `http://عنوان-الماك:8080`، وتعرف عنوان الماك من `ipconfig getifaddr en0`.
   وللإضافة لشاشة الرئيسية: مشاركة > Add to Home Screen.

## المتاح
أسهم وOK ورجوع ورئيسية وقائمة، صوت وكتم وقنوات، تشغيل/إيقاف، المصدر، تشغيل/إيقاف الوسائط، إرسال رابط لعرضه على الشاشة، كتابة نص (إنجليزي وأرقام)، فتح تطبيقات (عدّل `apps.json`)، وفتح الإعدادات والواي فاي وخيارات المطوّر.

## ملاحظات
- لا تفتح الجسر على الإنترنت، هو للشبكة المنزلية فقط.
- زر التشغيل يرسل KEYCODE_POWER وقد يختلف سلوكه من شاشة لأخرى؛ جرّب أيضاً sleep/wake من `server.py`.
- الرسيفر والاتصال بالبلوتوث ما دخلوا هنا، يجي بعد ما نتأكد أن ADB يشتغل.
